# 🐿️ Peanut the Squirrel — $PNUT

The squirrel that forks everything.

Peanut the Squirrel is a squirrel meme coin. Simple as that: cats sell,
dogs sell, and a squirrel with a fork brings luck to everyone who holds it.

## The coin

- **Name:** Peanut the Squirrel
- **Ticker:** $PNUT
- **Chain:** Solana
- **Launch:** [forks.wiki](https://forks.wiki) — one coin per repository,
  launched on this repo via pump.fun

## How it works

This repository is the home of the $PNUT coin. Its creator fees are split
on-chain, for good, between the people behind the code:

- **50%** to the launcher
- **30%** to the repository
- **20%** to forks

The split is locked at launch and can never be changed.
